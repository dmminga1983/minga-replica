# minga-replica

**Одиннадцать навыков Claude, которые воссоздают любое приложение по принципу «чистой комнаты» и делают его вашим: разбор, архитектура, дизайн, сборка, бэкенд, тесты, оценка полноты, что ненавидят пользователи оригинала, ребрендинг, запуск и деплой. С профилями регионов для России и для остального мира и описаниями для App Store, Google Play и RuStore.**

Часть экосистемы [Minga](https://github.com/dmminga1983/minga). Один навык разбирает приложение, которое вы хотите повторить, другой его собирает, третий тестирует, а ещё один читает его настоящие отзывы и превращает жалобы в причину, по которой ваша версия вообще нужна. Между ними: стек под страну продаж, дизайн-система, вход и оплата, оценка полноты, новое имя и бренд, лендинг и описания для магазинов, и проверка перед выкладкой. Бесплатно, MIT, без API-ключей, ничего подключать не нужно.

**Навыки повторяют то, что приложение делает, и никогда то, чем оно владеет.** Функции и сценарии написаны заново. Не его код, логотип, тексты или контент. Навыки сами за этим следят.

## Одиннадцать навыков

| команда | что делает |
| --- | --- |
| `/replica-recon` | Экраны, сценарии, компоненты, модель данных и матрица функций по публичным источникам и вашему собственному аккаунту. Задаёт регион: `ru`, `global` или `both`. |
| `/replica-architect` | Стек, схема базы и API под регион. `stack.py` выдаёт стек по умолчанию и юридический чек-лист. |
| `/replica-design` | Дизайн-система в виде токенов и спецификаций компонентов, с открытыми иконками и шрифтами с кириллицей. Контраст проверяется по WCAG. |
| `/replica-build` | Экран за экраном по карте разбора, со всеми состояниями, каждая строка пишется заново. |
| `/replica-backend` | Вход, база данных, оплата, почта, фоновые задачи, интеграции, чек-лист безопасности. |
| `/replica-test` | План тестов по сценариям, спецификации Playwright, баг-репорты по степени серьёзности. |
| `/replica-diff` | Оценка полноты по матрице функций и сравнение раскладки скриншотов без учёта цвета. |
| `/replica-users` | Настоящие отзывы, разложенные на «что бесит», «чего не хватает», «что не решено». Каждая цитата со ссылкой. |
| `/replica-brand` | Название, проверки товарного знака, палитра, бриф на логотип, голос бренда и поиск следов оригинала в коде. |
| `/replica-launch` | Лендинг, цены и описания для App Store, Google Play и RuStore с проверкой. |
| `/replica-deploy` | Проверка перед запуском, продакшен-сервисы, DNS, мониторинг, мобильные сборки. Выкладка только по вашей команде. |

## Регионы

`replica/region.txt` определяет стек, магазины, законы и проверки. `python3 skills/replica-architect/stack.py --region ru|global|both` выводит их.

| | Россия (`ru`) | Мир (`global`) |
| --- | --- | --- |
| данные | персональные данные записываются и хранятся в базах на территории России (152-ФЗ, строго с 1 июля 2025 года) | GDPR в ЕС, законы штатов о приватности в США |
| хостинг | Yandex Cloud, Selectel, VK Cloud, Timeweb Cloud | Vercel, Netlify, Fly.io, Render |
| вход | телефон или почта, VK ID, Яндекс ID, Сбер ID | почта, Google, Sign in with Apple |
| оплата | ЮKassa, CloudPayments, Т-Касса, Robokassa, с чеками по 54-ФЗ | Stripe, Paddle, Lemon Squeezy |
| магазины | RuStore; App Store; Google Play только бесплатно (с 26 декабря 2024 года нет выплат на российские банковские счета) | App Store, Google Play |
| товарный знак | открытые реестры ФИПС, WIPO | USPTO, EUIPO, WIPO |
| отзывы | RuStore, Отзовик, Irecommend, Хабр, VC.ru, Telegram, 2ГИС | G2, Capterra, Trustpilot, Reddit, Hacker News |

`both` значит, что заранее решается, где живут данные российских пользователей и какой платёжный сервис принимает какие карты. У каждой юридической строки в `regions.json` указана дата проверки.

## Установка

**Claude Code**, как плагин:

```
/plugin marketplace add dmminga1983/minga-replica
/plugin install minga-replica@minga-replica
```

Или скопируйте папки, чтобы команды назывались просто `/replica-recon` и так далее:

```bash
git clone https://github.com/dmminga1983/minga-replica.git
cp -r minga-replica/skills/replica-* ~/.claude/skills/
```

Запускайте по порядку. Каждый навык читает то, что предыдущий записал в папку `replica/` вашего проекта:

```
recon -> architect -> design -> build -> backend -> test -> diff -> users -> brand -> launch -> deploy
```

Любой можно запустить и отдельно: `/replica-users` на приложении, которое вы только думаете повторить, покажет, стоит ли.

## Инструменты

Чистый Python без зависимостей, без сети, Python 3.8 или новее.

```bash
python3 skills/replica-architect/stack.py --region both
python3 skills/replica-diff/parity.py replica/features.csv
python3 skills/replica-diff/imgdiff.py original.png clone.png --out diff.png
python3 skills/replica-users/reviews.py replica/reviews.csv --out replica/feedback.md
python3 skills/replica-design/contrast.py replica/design/tokens.json
python3 skills/replica-brand/sweep.py . --config replica/brand.json
python3 skills/replica-launch/listing.py replica/launch/listing.json
```

- **`imgdiff.py`** читает PNG без библиотек, сравнивает карты контуров по сетке и не учитывает цвет, поэтому ребрендинг не считается отличием.
- **`parity.py`** взвешивает must, should и could, считает частичное за половину, не учитывает то, что вы намеренно пропустили или добавили сами, и пишет «не готово к выпуску», пока не сделана хоть одна обязательная функция.
- **`reviews.py`** отбрасывает отзывы без ссылки, цитирует только ваши строки, помечает темы меньше чем из трёх отзывов или из одного источника как слабые, понимает русский и английский.
- **`sweep.py`** находит имя оригинала внутри идентификаторов, в именах файлов и в русской транслитерации, а также его домены и цвета, и не даёт выложить приложение, пока всё не вычищено.
- **`listing.py`** проверяет лимиты App Store, Google Play и RuStore, заявления вроде «№1», эмодзи, впустую потраченные ключевые слова и имя оригинала во всех языковых версиях.

```bash
python3 -m unittest discover -s tests -v
```

## Важные оговорки

- **Чистая комната.** Навыки изучают, что приложение делает и как по нему двигаются люди, а потом пишут всё заново. Никогда исходный код, закрытые API, ресурсы, логотипы, товарные знаки или тексты оригинала.
- **Только то, что вам можно читать.** Публичные страницы и ваш собственный аккаунт. Никогда чужой аккаунт, никогда в обход входа или платного доступа, никогда вопреки правилам сайта.
- **Ребрендинг до запуска обязателен.** `/replica-deploy` не выложит приложение, пока поиск следов оригинала не будет чистым.
- **«Любое приложение» значит функции и сценарии**, а не контент, сеть пользователей или лицензии, которыми владеет приложение.
- **Идеального клона никто не обещает.** `/replica-recon` честно оценивает объём, а `/replica-diff` даёт реальную цифру.
- **Ничего не выдумывается.** Никаких придуманных отзывов, цитат, пользователей и цифр, никаких фальшивых отзывов на вашем лендинге.
- **Ключи у вас.** Claude никогда не создаёт аккаунты, не вводит карты и пароли, не вставляет боевые ключи. Он пишет `.env.example`, а `.env.local` заполняете вы.
- **Это не юридическая консультация.** Проведите проверки товарного знака, прочитайте условия используемых сервисов и поговорите с юристом перед запуском, если на кону деньги. Законы и правила магазинов меняются: в `regions.json` и `stores.json` указаны даты проверки.
